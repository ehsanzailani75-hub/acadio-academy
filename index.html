REFERENCE LIBRARY

Code Library

Rujukan asas. Maksud kod sepuluh tidak seragam di semua agensi; semak senarai rasmi organisasi masing-masing.

Radio phrase

Over — Saya selesai bercakap; pihak lain boleh membalas.

Out — Perbualan tamat.

Stand by — Sila tunggu sebentar.

Say again — Sila ulang mesej.

Communication etiquette

• Fikir mesej sebelum bercakap.

• Gunakan ayat ringkas dan jelas.

• Tunggu giliran bercakap.

• Jangan anggap satu kod mempunyai maksud universal.

Ten-code awareness

Kod seperti “10-4” sering digunakan untuk menyatakan mesej diterima, tetapi maksud kod lain boleh berbeza mengikut organisasi dan negara. Gunakan bahan rasmi organisasi sebagai rujukan.
